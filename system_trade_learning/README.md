# システムトレード学習ガイド

このディレクトリには、Pythonを使ったシステムトレード（アルゴリズムトレード）の基礎を学ぶためのサンプルコードが含まれています。

## 1. システムトレードとは？

システムトレードとは、あらかじめ決めた「売買ルール」に従って機械的に取引を行う手法です。感情を排し、過去のデータに基づいて有効性を検証（バックテスト）できるのが特徴です。

主なプロセス：
1. **データ取得**: 株価などのヒストリカルデータを集める。
2. **戦略構築**: 「いつ買って、いつ売るか」のルールを作る。
3. **バックテスト**: 過去のデータでそのルールの成績をテストする。
4. **評価・改善**: リターンやリスクを確認し、ルールを調整する。

## 2. サンプルコードについて

`simple_backtest.py` は、最も基本的な「移動平均線クロス（ゴールデンクロス・デッドクロス）」戦略を実装したサンプルです。

### 戦略のロジック
- **買いシグナル (ゴールデンクロス)**: 短期移動平均線(50日)が、長期移動平均線(200日)を**下から上に**抜けた時。
- **売りシグナル (デッドクロス)**: 短期移動平均線が、長期移動平均線を**上から下に**抜けた時（今回はポジションを解消して現金にします）。

### 使用しているライブラリ
- `yfinance`: Yahoo Financeから株価データを取得
- `pandas`: データの表形式での操作・計算
- `matplotlib`: グラフ描画

## 3. 実行方法

ターミナルで以下のコマンドを実行してください。

```bash
# 必要なライブラリのインストール
pip install -r requirements.txt

# バックテストの実行
python3 simple_backtest.py
```

実行すると、コンソールに結果のサマリーが表示され、同じディレクトリに `backtest_result.png` という画像ファイルが生成されます。この画像には、資産曲線の推移と売買ポイントが描画されています。

## 4. 学習の次のステップ

コードを編集して、いろいろ試してみましょう。

1. **銘柄を変える**: `TICKER = 'SPY'` を `'AAPL'` (Apple) や `'BTC-USD'` (Bitcoin) に変えてみる。
2. **期間を変える**: `SHORT_WINDOW` (短期) や `LONG_WINDOW` (長期) の日数を変えて、成績がどう変わるか見る。
3. **別の戦略を試す**: 例えば「RSIが30以下なら買い、70以上なら売り」といったロジックを実装してみる。

Happy Trading!
