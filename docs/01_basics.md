# システムトレードの基礎知識

## 1. システムトレードとは？

**システムトレード（アルゴリズムトレーディング）** とは、明確なルールに基づいて自動的に売買判断を行うトレード手法です。

### 従来のトレードとの違い

| 項目 | 裁量トレード | システムトレード |
|------|-------------|-----------------|
| 判断基準 | 勘・経験・感情 | 明確なルール・アルゴリズム |
| 実行速度 | 人間の反応速度 | ミリ秒単位で実行可能 |
| 一貫性 | 感情に左右される | 常に一貫したルールで実行 |
| 検証 | 困難 | バックテストで検証可能 |

### システムトレードのメリット

1. **感情を排除** - 恐怖や欲望に左右されない
2. **一貫性** - 決められたルールに従って常に実行
3. **バックテスト可能** - 過去データで戦略を検証できる
4. **24時間稼働** - 人間が見ていなくても動作
5. **複数市場の監視** - 同時に多くの銘柄を監視可能

### システムトレードのデメリット

1. **過剰最適化のリスク** - 過去データに過度にフィットする危険
2. **市場環境の変化** - 過去に有効だった戦略が将来も有効とは限らない
3. **技術的障害** - システム障害、通信エラーなどのリスク
4. **開発コスト** - プログラミング知識が必要

## 3. 重要な用語

### テクニカル指標

| 用語 | 説明 |
|------|------|
| **移動平均線 (MA)** | 過去n期間の平均値を線でつないだもの |
| **RSI** | 相対力指数。買われすぎ・売られすぎを判断 (0-100) |
| **MACD** | 2つの移動平均線の差を利用したトレンド指標 |
| **ボリンジャーバンド** | 移動平均±標準偏差で価格の変動範囲を表示 |

### トレード用語

| 用語 | 説明 |
|------|------|
| **ロング (買い)** | 価格上昇を期待して買う |
| **ショート (売り)** | 価格下落を期待して売る（空売り） |
| **ポジション** | 保有している売買状態 |
| **エントリー** | ポジションを持つこと（売買開始） |
| **イグジット** | ポジションを解消すること（売買終了） |

## 4. バックテストとは

**バックテスト**とは、過去の市場データを使ってトレード戦略をシミュレーションすることです。

### バックテストの流れ

```
1. 戦略のルールを定義
   ↓
2. 過去データを取得
   ↓
3. ルールに従って仮想的に売買
   ↓
4. パフォーマンスを評価
   ↓
5. 戦略を改善
```

### 主要なパフォーマンス指標

| 指標 | 説明 | 目安 |
|------|------|------|
| **総リターン** | 投資期間全体の利益率 | プラスが望ましい |
| **シャープレシオ** | リスク調整後リターン | 1以上が良い |
| **最大ドローダウン** | 最大の資産減少率 | 20%以下が望ましい |
| **勝率** | 利益が出た取引の割合 | 50%以上 |
| **プロフィットファクター** | 総利益÷総損失 | 1.5以上が望ましい |

## 5. リスク管理の基本

### ポジションサイジング

「1回の取引でどれだけの資金を投入するか」を決めるルール。

**一般的なルール:**
- 1取引あたりのリスクは資金の1-2%以下
- 複数ポジションの合計リスクは10%以下

### ストップロス（損切り）

損失を限定するために、一定の損失に達したら自動的にポジションを閉じる。

```python
# 例: 買値から5%下落したら損切り
stop_loss = entry_price * 0.95
```

### 分散投資

- 複数の銘柄・市場に分散
- 複数の戦略を組み合わせる
- 相関の低い資産を選ぶ

## 6. システムトレードの開発プロセス

```
1. アイデア
   │ 市場の非効率性を見つける
   ↓
2. 仮説
   │ 「〇〇すれば利益が出る」という仮説を立てる
   ↓
3. 実装
   │ プログラムとして戦略を実装
   ↓
4. バックテスト
   │ 過去データで検証
   ↓
5. 最適化
   │ パラメータを調整（過剰最適化に注意）
   ↓
6. ウォークフォワードテスト
   │ 未知のデータで検証
   ↓
7. ペーパートレード
   │ 実際の市場でリアルタイムテスト（仮想資金）
   ↓
8. 実運用
   │ 少額から開始し、徐々に規模を拡大
```

---

## 7. 注意事項

### 過剰最適化 (Overfitting)

過去データに過度にフィットさせると、将来のデータでは機能しなくなります。

**対策:**
- シンプルな戦略を心がける
- パラメータ数を最小限に
- 複数の期間でテスト
- ウォークフォワード分析を実施

### 生存者バイアス

現在も上場している銘柄だけでバックテストすると、過度に楽観的な結果になります。

**対策:**
- 上場廃止銘柄も含めたデータを使用
- 複数の市場でテスト
